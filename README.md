# Modern Developer Portfolio | Full-Stack & AI/ML Engineer

A high-performance, responsive developer portfolio engineered to showcase production full-stack web applications, applied computer vision pipelines, and intelligent AI microservices.

![Tech Stack](https://img.shields.io/badge/Stack-React%2019%20%7C%20Tailwind%20CSS%20v4%20%7C%20Vite-06b6d4)
![License](https://img.shields.io/badge/License-MIT-emerald)

---

## 🌟 Features

- **Dark & Light Mode Glassmorphism**: Tailored theme with smooth backdrop-blur glass panels, cyan/teal neon accents, and high-contrast typography in both dark and light modes.
- **Scrollspy Navigation**: Real-time section tracking with dynamic active indicator pills.
- **Featured Flagship Projects**: Includes **KeyProctor** (isolated C++ code execution engine + keystroke biometrics), **Growthhub**, **TheDoctor**, and **EYeOn** with Google XYZ impact metrics.
- **Interactive Skills Matrix**: 5 specialized domains (Languages, Frontend, Backend, AI/ML, Databases) with confidence meters and proficiency badges.
- **Chronological Experience Timeline**: Vertical neon track with milestone nodes and engineering impact highlights.
- **Direct Contact Hub**: Instant clipboard copying, pre-filled mailto dispatch, and one-click Gmail web compose.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Tailwind CSS v4, Lucide React
- **Build Tool**: Vite 7
- **Styling**: Modern CSS3 Grid/Flexbox, Glassmorphism, CSS float keyframes
- **Deployment**: Vercel ready

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/<your-username>/<repo-name>.git

# Navigate to the project directory
cd portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

### Production Build

```bash
# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```

---

## ☁️ Deploying to Vercel

1. Push this repository to your GitHub account.
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Import this repository.
4. Framework Preset will auto-detect **Vite**.
5. Click **Deploy**.
